How It Works

Three operations.
Infinite continuity.

01

Observe

Continuity passively monitors every AI chat session in VSCode — capturing decisions, file edits, reasoning chains, and constraint statements in real time.

// continuity.observe()
session.on('message', (msg) => {
classifier.extract(msg,
['decision', 'constraint',
'file_ref', 'anti_context']
)
})
02

Store

Extracted events are structured into a local context graph — indexed by task, file, and time. Stored entirely on-device. No cloud, no telemetry.

# context_store.json
{
"decisions": [
"exponential backoff",
"idempotency via header"
],
"anti_context": ["fixed delay"]
}
03

Transfer

On context limit or tool switch, Continuity auto-generates a dense rehydration prompt and injects it into the new session — in milliseconds.

// auto-triggered on switch
continuity.transfer({
from: 'copilot',
to: 'claude',
latency: 2100 // ms
})
